Who found what

Every detection snare has for this campaign came from someone finding it on their own machine first and writing up what they saw. None of it was found by reading code.

  1. @kleenpulse — campaign 4738-2, from a live Windows hostThe patched cli.js Defender missed, the PowerShell clipboard stealer, api.js wired into run scripts, and forged force-pushes reading 1 ahead, 1 behind. snare now detects all four. #47
  2. @ibraheembello — npm on Windows was never checkedsnare doctor printed no npm installation found to check on every Windows host while a trojanised cli.js sat in %APPDATA%\npm and ran on every command. Also suggested the size heuristic that now catches this without knowing the malware at all. #46
  3. @SamuelOshin — four remediation bugsA 0-byte fake font that fix skipped, a tasks.json with comments that fix deleted whole, a phantom origin branch pushed to the remote, and a failed push reported as a success. All four reproduced exactly as described. #44
  4. @phoenixdahdev — remediation deleted the files it was meant to cleansnare fix removed build configs instead of stripping them, so the fix was its own outage. #39
Still unanswered

The two questions nobody has answered

These are not rhetorical. Nine infections across five contributor identities over two years is not one laptop, and no delivery mechanism has been established.

  1. How does this family actually reach developer machines?Every payload so far modified an existing clean config, so a contaminated template isn't the whole story. A shared upstream (scaffold, create-*, theme, extension) is the leading, unproven theory. One chain is on record (#47): an IDE language server ran npx -y chrome-devtools-mcp@latest through an already-patched global npm. That explains how it keeps running, not how it arrived.
  2. Can a defence propagate the way the infection does?Without becoming a dropper itself. This is an open design question, and a genuinely uncomfortable one.

Before you post details

Redact tokens, keys and hostnames. "A fintech I contract for" is fine. Rather not post publicly? Open an issue saying so.
